# Starter Template Plan
*The complete manifest of files that make up a new project conforming to the architecture canon. Use this to build the starter repository.*

---

## How to use this document

Each file below is marked with a status:

- **CUSTOM** — content inlined here; code is canon-specific and cannot be obtained elsewhere
- **STANDARD** — generated by a CLI command (e.g. `npx create-next-app`, `shadcn add button`); follow the standard install
- **CONFIG** — small configuration file, content inlined here
- **REFERENCE** — its full implementation is documented in a canon section or guideline; copy from there

Build order:
1. Run the bootstrap commands (creates the standard files)
2. Copy in the CUSTOM and CONFIG files from this document
3. Generate the example `users` module
4. Verify by running `npm test` and `npm run test:e2e`

---

## Bootstrap commands

```bash
# Create the Next.js project
npx create-next-app@latest my-app \
  --typescript \
  --tailwind \
  --eslint \
  --app \
  --src-dir false \
  --import-alias "@/*"

cd my-app

# Core dependencies
npm install drizzle-orm postgres zod pino better-auth

# Dev dependencies
npm install -D drizzle-kit pino-pretty vitest @vitest/ui \
  @playwright/test tsx

# shadcn/ui
npx shadcn@latest init
npx shadcn@latest add button input label card dialog \
  toast checkbox select textarea form

# Playwright
npx playwright install
```

### `lib/env.ts`

```typescript
import { z } from 'zod'

const envSchema = z.object({
  DATABASE_URL:        z.string().url('DATABASE_URL must be a valid URL'),
  BETTER_AUTH_SECRET:  z.string().min(32),
  BETTER_AUTH_URL:     z.string().url(),
  NODE_ENV:            z.enum(['development', 'production', 'test']).default('development'),
  NEXT_PUBLIC_APP_NAME: z.string().default('App'),
  WEBHOOK_SECRET:      z.string().optional(),
})

const parsed = envSchema.safeParse(process.env)
if (!parsed.success) {
  console.error('❌ Invalid environment configuration:')
  console.error(parsed.error.flatten().fieldErrors)
  throw new Error('Invalid environment configuration — see errors above')
}

export const env = parsed.data
```

### `lib/audit.ts`

```typescript
import { db } from '@/db'
import { auditLog } from '@/db/schema'
import { logger } from './logger'
import type { CallerContext } from './auth/caller-context'

export const audit = {
  record({
    action,
    resourceId,
    ctx,
    metadata,
  }: {
    action:     string
    resourceId: string
    ctx:        CallerContext
    metadata?:  Record<string, unknown>
  }): void {
    db.insert(auditLog)
      .values({
        action,
        resourceId,
        orgId:      ctx.orgId,
        userId:     ctx.userId,
        callerType: ctx.callerType,
        agentId:    ctx.agentId    ?? null,
        sessionId:  ctx.sessionId  ?? null,
        metadata:   metadata       ?? null,
      })
      .catch((err) => {
        logger.warn('audit.write.failed', {
          action, resourceId, orgId: ctx.orgId, error: err.message,
        })
      })
  },
}
```

### `app/error.tsx`

```tsx
'use client'

import { useEffect } from 'react'
import { Button } from '@/components/ui/button'

export default function GlobalError({
  error, reset,
}: {
  error: Error & { digest?: string }
  reset: () => void
}) {
  useEffect(() => {
    // Errors are logged server-side via Next.js telemetry
    // The digest connects browser errors to server logs
    console.error('Unhandled error:', error.digest)
  }, [error])

  return (
    <div className="flex flex-col items-center justify-center min-h-[60vh] gap-4 p-6">
      <h2 className="text-lg font-medium">Something went wrong</h2>
      <p className="text-sm text-muted-foreground">
        An unexpected error occurred.
        {error.digest && <span className="block">Reference: {error.digest}</span>}
      </p>
      <Button onClick={reset}>Try again</Button>
    </div>
  )
}
```

### `middleware.ts`

```typescript
import { NextResponse } from 'next/server'
import type { NextRequest } from 'next/server'
import { auth } from '@/lib/auth'

export async function middleware(request: NextRequest) {
  const session = await auth.api.getSession({ headers: request.headers })

  const isAuthRoute      = request.nextUrl.pathname.startsWith('/login')
  const isDashboardRoute = request.nextUrl.pathname.startsWith('/dashboard')

  if (isDashboardRoute && !session) {
    return NextResponse.redirect(new URL('/login', request.url))
  }

  if (isAuthRoute && session) {
    return NextResponse.redirect(new URL('/dashboard', request.url))
  }

  return NextResponse.next()
}

export const config = {
  matcher: ['/dashboard/:path*', '/login'],
}
```

## Verification — proving the starter works

After bootstrap and adding all CUSTOM files:

1. `npm run db:generate` — should produce a clean initial migration
2. `npm run db:migrate` — should run without errors
3. `npm run dev` — should start without errors
4. Visit `http://localhost:3000/api/health` — should return `{"status":"ok"}`
5. `npm test` — should run with 0 tests (no module yet)
6. `npm run scaffold:module users` — should generate the users module
7. `npm run db:generate` — should produce a users migration
8. `npm run db:migrate` — should apply it
9. `npm test` — should run users.schema.test and users.service.test, all passing
10. `npm run test:e2e` — should run users.spec.ts, passing

If all 10 steps pass, the starter is verified.
